# LeetCode 150 practice roadmap

This is a personal 150-problem interview practice set from the supplied workbook, arranged in the repository’s topic pages so each solution has a natural home. It contains 29 Easy, 101 Medium, and 20 Hard problems.

## How the tracker works

- Each topic page is the source of truth for its problems and progress.
- The roadmap number preserves the workbook’s sequence; it is not LeetCode’s own problem number.
- The Day column preserves the workbook’s 90-day plan.
- Start a solution in your own words, then add its Java class and JUnit test using [How to add a solution](ADDING_A_SOLUTION.md).
- After the code and tests are in the repo, change its status to `Solved`, link the Java class and test, and record the actual time and space complexity for your implementation.
- Review the problem after a few days. Keep the original problem statement on LeetCode; this repository stores links and your own notes/code.

## 90-day rhythm

The workbook schedules review sessions on days 7, 14, 21, 28, 35, 42, 49, 56, 63, 70, 77, and 84. Use each to retry the previous six days’ problems without looking at your notes first.

On day 89, solve [Reverse Integer](https://leetcode.com/problems/reverse-integer/) and then revisit your five weakest problems. Day 90 is a mock interview: choose two random Medium problems and one Hard problem, with a 45-minute limit for each.
